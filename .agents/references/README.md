# Agent References

This directory stores large reference documents that are useful but should not
be discovered as native skills.

## Files

- `apps-in-toss/index.md`: Apps in Toss developer docs index snapshot.
- `tds-mobile/index.md`: TDS Mobile reference snapshot.

## Loading Rule

Only read these files when a resolved guide, skill, or task explicitly needs
their content. Do not place loose `.md` files under `.agents/skills/`; native
skills must live in directories with `SKILL.md`.
