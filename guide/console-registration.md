# Console Registration

## App Creation Modal

Register the app at <https://apps-in-toss.toss.im/>.

When starting from the "앱 만들기" modal, fill and report every field below:

- 만들고 싶은 앱 설명: required, at least `10` Korean characters. Write a
  concise sentence describing the service users will launch, not just the app
  name. Do not include the word `미니앱`. Do not end the description with the
  word `앱`.
- 앱 이름: required Korean display name. Generated by the `app-naming`
  subagent during app creation. Use the same name that will be shown in the
  console metadata.
- appName: required app identifier. Use lowercase kebab-case, and make it match
  `granite.config.ts` exactly.
- 앱 유형: required. Select `비게임` unless the implemented app is actually a
  game with game rules, scoring, or gameplay loops.

For a medication timer app, use:

- 만들고 싶은 앱 설명: `복용 시간을 등록하고 오늘 먹은 알약을 체크해요`
- 앱 이름: `알약 타이머`
- appName: `pill-timer`
- 앱 유형: `비게임`

## App Creation Subagents

When creating a new mini-app, always trigger the following subagents as script
steps before filling the console "앱 만들기" modal or writing
`submission/inputs.md`. Each subagent is a skill under `.agents/skills/` and
must be invoked via `run_subagent` or equivalent script call with the app
function description, core object/action, and target category as input.

1. **`app-naming` subagent** - Generates the Korean app name, English app name,
   and appName. The name must clearly communicate the app's function or category
   at a glance, then add a rhythmic, memorable cadence.
2. **`app-seo-keywords` subagent** - Generates the app search keyword list
   optimized for user search intent and the app's product category.

Do not skip these subagents or fill naming/keywords manually. The subagent
output is the canonical source for the console fields.

## Registration Flow

1. Register the app in the console.
2. Upload the `.ait` bundle in 앱 출시.
3. Test via QR code in the Toss app.
4. No 사업자 등록 is needed to submit; it is only needed for IAP/settlement.
