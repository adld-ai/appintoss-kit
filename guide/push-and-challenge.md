# Push and Challenge

## Push Notifications

Push notifications, including 스마트 발송, require:

- mTLS certificate
- console campaign creation
- 문구 검수, which is a human copy review process
- 알림 동의문 consent flow
- backend server

Plan lead time for 문구 검수. Push is not feasible for short-deadline hacks.

## Vibe-Coding Challenge

For the 바이브코딩 챌린지:

1. Register the app in the console with 앱 이름, appName, and 앱 유형.
2. Upload the `.ait` bundle by the deadline.
3. Submit the 신청폼 at <https://toss.im/_m/JTkiSRsh> with app name, appName,
   description, and theme relevance.
4. Judging:
   - 1차 심사: active users over a period
   - 최종 심사: completeness, theme fit, UX
